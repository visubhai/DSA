# DSA

Data structures and algorithms practice in C++. Following Striver's 
A2Z DSA sheet and solving problems from LeetCode and Codeforces.

## Structure

- `striver/` — Solutions organized by Striver's A2Z sheet topics
  - `sorting/` — Sorting algorithm implementations (selection, bubble, 
    insertion, merge, quick)
- `leetcode/` — LeetCode problem solutions (coming soon)
- `codeforces/` — Codeforces contest solutions (coming soon)

## Goal

Build deep DSA fundamentals through daily practice and competitive 
programming.
